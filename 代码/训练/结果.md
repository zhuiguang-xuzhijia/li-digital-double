# 训练结果（第一次真实数据实验）

> 2026-11-14｜结论：**判死刑的验证没过。** 在这个设置下，情境里没有可学的信号。

---

## 一、数据

来源：[Persona-CAPS](https://aclanthology.org/2026.emnlp-main.1495/)（EMNLP 2026）开源的 `data/if_then/`，
从公开经验取样（ESM）数据里挖出的「情境 → 行为」条目。

```
patterns.all.jsonl    546 条
  situation_text      "deep thinking is required"
  behavior_key        "deep_thinker"
  effect_size         0.818      ← 该情境下该行为比平时高多少（Cohen's d）
  n_situation_active  268        ← 可当置信权重

61 个行为类 · 27 个情境类 · 10 个（大五 × 高低）格子
```

获取方式：`raw.githubusercontent.com` 不通，走 GitHub API 的 base64 通道（见 `拉数据.py`）。

⚠️ **数据不随仓库发布**：上游许可证为 `NOASSERTION`，默认保留所有权利。要用请自己拉。

## 二、任务与模型

**任务**：配对判别 —— 真实（情境, 行为）配对 vs 打乱配对。

**模型**（零依赖，手写梯度）：

```
情境 s → 词袋哈希 → x ∈ R^64
行为 b → 可学习向量 e_b
分数 f(s,b) = x·e_b + 偏置_b
损失 逻辑损失（正=真配对，负=打乱配对）
```

**切分**：按（情境, 行为）配对切，训练 436 / 测试 110；
负样本分训练/测试两份，**配对零重叠**。

## 三、结果

| | AUC | hit@1 |
|---|---|---|
| 随机 | 0.499 | 0.045 |
| 多数类（quiet） | 0.500 | 0.045 |
| **本模型** | **0.551** | **0.009** |
| 置换对照（打乱重训 3 次） | 0.540 / 0.591 / 0.534，均值 **0.555** | — |

**真模型 0.551 ≈ 置换对照 0.555。**

模型学到的，和把标签打乱学到的一样多。hit@1 还**低于**多数类（0.009 vs 0.045）。

## 四、中途抓到一个评测泄漏

第一版结果 AUC 0.638，看起来有信号。但置换对照跑出 **0.73**——**比真模型还高**。

原因：负样本同时用于训练和评测，模型把它们背下来了。

修法：负样本按训练/测试拆开，配对严格不重叠（校验输出「重叠 0」）。修完后真模型掉到 0.551。

**教训：置换对照不是可选项。** 没有它，我们会把一个坏指标当成好消息写进论文。

## 五、为什么失败（四条，按可能性排）

1. **类别太细，样本太少**：61 类 / 436 条 ≈ 每类 7 条，学不到类边界。
2. **特征太粗**：英文词袋哈希。语义相近的句子（"deep thinking" vs "alone and lonely"）在词袋里几乎无重叠。
3. **任务选错了**：随机负样本往往**也是合理的**（"lonely" 配 "quiet" 并不荒谬），所以这个判别任务本身偏难。
4. **指标本身有偏**：打乱后还能到 0.555，说明正负样本的分数分布本来有系统性差异。

## 六、下一步

| 做法 | 成本 | 评价 |
|---|---|---|
| 换句向量特征 | 低 | 只解决第 2 条 |
| 61 类并成 ~10 类 | 低 | 只解决第 1 条 |
| **换数据：openESM** | 中 | **换问题——这才是关键** |

**我的判断：不是继续调，是换问题。**

CAPS 数据答的是「心理情境 → 行为倾向」，我们要答的是「人生事件 → 情绪强度 + 衰减时间」。

**两个问题不一样。** 用前者的失败推断后者不成立，是过度推论；反过来，继续在这个数据上调，也调不出我们要的东西。

## 七、这个实验的真正价值

**它证明了"合成数据上的 100%"是不可信的。**

`原型_可训练检索.py` 在合成任务上损失 2.36→0.12、准确率 0→100%。
现在同样的方法在真实数据上等于随机。

> **合成任务验证的是"梯度是对的"，真实数据验证的是"信号存在吗"。**
> 前者已经证明，后者刚刚证伪（至少在这个数据上）。

这句话应该写进论文，因为照着做的人会撞同一堵墙。
