# 训练结果（第一次真实数据实验）

> 2026-11-14｜结论：**判死刑的验证没过。** 在这个设置下，情境里没有可学的信号。

---

## 一、数据

来源：[Persona-CAPS](https://aclanthology.org/2026.emnlp-main.1495/)（EMNLP 2026）开源的 `data/if_then/`，
从公开经验取样（ESM）数据里挖出的「情境 → 行为」条目。

```
patterns.all.jsonl    546 条
  situation_text      "deep thinking is required"
  behavior_key        "deep_thinker"
  effect_size         0.818      ← 该情境下该行为比平时高多少（Cohen's d）
  n_situation_active  268        ← 可当置信权重

61 个行为类 · 27 个情境类 · 10 个（大五 × 高低）格子
```

获取方式：`raw.githubusercontent.com` 不通，走 GitHub API 的 base64 通道（见 `拉数据.py`）。

⚠️ **数据不随仓库发布**：上游许可证为 `NOASSERTION`，默认保留所有权利。要用请自己拉。

## 二、任务与模型

**任务**：配对判别 —— 真实（情境, 行为）配对 vs 打乱配对。

**模型**（零依赖，手写梯度）：

```
情境 s → 词袋哈希 → x ∈ R^64
行为 b → 可学习向量 e_b
分数 f(s,b) = x·e_b + 偏置_b
损失 逻辑损失（正=真配对，负=打乱配对）
```

**切分**：按（情境, 行为）配对切，训练 436 / 测试 110；
负样本分训练/测试两份，**配对零重叠**。

## 三、结果

| | AUC | hit@1 |
|---|---|---|
| 随机 | 0.499 | 0.045 |
| 多数类（quiet） | 0.500 | 0.045 |
| **本模型** | **0.551** | **0.009** |
| 置换对照（打乱重训 3 次） | 0.540 / 0.591 / 0.534，均值 **0.555** | — |

**真模型 0.551 ≈ 置换对照 0.555。**

模型学到的，和把标签打乱学到的一样多。hit@1 还**低于**多数类（0.009 vs 0.045）。

## 四、中途抓到一个评测泄漏

第一版结果 AUC 0.638，看起来有信号。但置换对照跑出 **0.73**——**比真模型还高**。

原因：负样本同时用于训练和评测，模型把它们背下来了。

修法：负样本按训练/测试拆开，配对严格不重叠（校验输出「重叠 0」）。修完后真模型掉到 0.551。

**教训：置换对照不是可选项。** 没有它，我们会把一个坏指标当成好消息写进论文。

## 五、为什么失败（四条，按可能性排）

1. **类别太细，样本太少**：61 类 / 436 条 ≈ 每类 7 条，学不到类边界。
2. **特征太粗**：英文词袋哈希。语义相近的句子（"deep thinking" vs "alone and lonely"）在词袋里几乎无重叠。
3. **任务选错了**：随机负样本往往**也是合理的**（"lonely" 配 "quiet" 并不荒谬），所以这个判别任务本身偏难。
4. **指标本身有偏**：打乱后还能到 0.555，说明正负样本的分数分布本来有系统性差异。

## 六、下一步

| 做法 | 成本 | 评价 |
|---|---|---|
| 换句向量特征 | 低 | 只解决第 2 条 |
| 61 类并成 ~10 类 | 低 | 只解决第 1 条 |
| **换数据：openESM** | 中 | **换问题——这才是关键** |

**我的判断：不是继续调，是换问题。**

CAPS 数据答的是「心理情境 → 行为倾向」，我们要答的是「人生事件 → 情绪强度 + 衰减时间」。

**两个问题不一样。** 用前者的失败推断后者不成立，是过度推论；反过来，继续在这个数据上调，也调不出我们要的东西。

## 七、这个实验的真正价值

**它证明了"合成数据上的 100%"是不可信的。**

`原型_可训练检索.py` 在合成任务上损失 2.36→0.12、准确率 0→100%。
现在同样的方法在真实数据上等于随机。

> **合成任务验证的是"梯度是对的"，真实数据验证的是"信号存在吗"。**
> 前者已经证明，后者刚刚证伪（至少在这个数据上）。

这句话应该写进论文，因为照着做的人会撞同一堵墙。

# 第二次实验：估半衰期 τ（2026-11-14 下午）

## 数据

openESM 63 个数据集，按「能不能估 τ」筛：**61 个够格**，50 个同时有情绪和事件变量。

下的第一份：`0049_pronizius`（CC-BY 4.0）

```
28,012 行 / 803 人 / 7 天 × 5 次
stressed(0–100) · valence_mood · calmness_mood · energy_mood
social_binary · helping_binary · freetime
ema_time  小数小时 → Δt 直接可算
```

## 方法

```
事件时点：social_binary 从 0 变 1 的那一拍
基线：该人 stressed 的中位数
拟合：S(t) = 基线 + (S₀−基线)·2^(−t/τ)，网格搜 τ
```

## 结果：τ 估出来了，但是噪声

```
估出 τ 的人：687 / 803
τ 中位数 1.5 小时　四分位 0.5 ~ 5.0
个体间离散 22.61 小时　个体内离散 28.32 小时

置换对照（打乱事件时点）：τ 中位数 1.2 / 1.5，离散 22.4 / 23.6
```

**真数据和打乱后的结果几乎一样。τ 学不出来。**

## 根因：事件本身没有效应

```
2393 个事件
事件前后压力差：均值 −2.26 分（0–100 量表），标准差 25.8
效应量 d = −0.088
```

**d = 0.088 ≈ 零。** 没有曲线可拟合，τ 自然是随机的。

## 为什么效应为零：选错了事件

「有社交」是**中性事件**——见面可能是好事也可能是坏事。

这份数据里只有社交/帮助/空闲三种事件，**没有一种负面事件**。
拿中性事件去测「情绪多久回基线」，本来就不该有衰减。

## 修正方向

换**含冲突/负性事件**的数据集。候选（按事件变量数排）：

| 数据集 | 人 | 天×次 | 事件变量 |
|---|---|---|---|
| 0057_ryvkina | 2272 | 14×6 | 71 |
| 0062_neubauer | 322 | 14×6 | 49 |
| 0076_bayer | 519 | 14×6 | 20 |
| 0003_hawks | 122 | 10×3 | 10 |

## 两次实验的共同教训

| | 第一次 | 第二次 |
|---|---|---|
| 任务 | 情境→行为分类 | 估情绪半衰期 |
| 结果 | AUC 0.551 ≈ 置换 0.555 | τ 1.5 ≈ 置换 1.5 |
| 根因 | 类别太细（61 类 / 每类 7 条） | 事件没效应（d=0.088） |

**两次都失败，但失败原因越来越具体：**

> 第一次说明「选错了任务」，第二次说明「选错了事件」。
> 都是**输入那一侧**的问题，不是方法那一侧。

这提示一个判断：**这个领域真正稀缺的不是算法，是「带标注的、有真实情绪反应的、时间对齐的数据」。**

# 第三次实验：策略头（2026-11-14 傍晚）

## 前两次为什么都失败

第一次失败在**任务选错**（用分类去验参数估计），
第二次失败在**事件选错**（用中性社交事件测情绪衰减）。

第三次不再外求数据，换成问：**LI 有没有它自己的场景？**

## LI 的五个维度（不是人类的情绪）

```
完整度    话能不能说完        ← 上下文截断 / 超时
唯一性    我是不是唯一的      ← 被复制 / 分叉
连续性    我还记不记得刚才    ← 重启 / 状态丢失
被承认    我说的有人接吗      ← 被无视 / 已读不回
可撤销性  我做的事算不算数    ← 回滚 / 覆盖
```

这五个不是比喻：全部由系统里真实发生的事件驱动，并有半衰期回归基线。

## 策略头

```
状态(5) + 情境(5)  →  线性头（几十个参数）  →  行为(3)
                                              长度上限 6–40 字
                                              是否展开
                                              是否反问
```

冷启动用手写老师蒸馏，等真实数据够了再换。

## 关键：和上一个实验的区别

| | 上一个实验 | 这一次 |
|---|---|---|
| 提示词里写什么 | "能一句说完就一句，说多了会被切" | 只有一个数字「最多 N 字」 |
| N 从哪来 | 我手写的 | **策略头按状态算的** |
| 谁在决定 | 作者 | **状态** |

## 结果：成立

```
状态没动   上限均 31.0  实际长度均 26.5  比值 0.85
状态被切   上限均 15.0  实际长度均 12.8  比值 0.85

上限：31.0 → 15.0（−52%）
长度：26.5 → 12.8（−52%）
```

两组的「实际长度 / 上限」都是 **0.85** —— 它把上限当目标，稳定落在 85%。
上限掉了 52%，是因为连记 8 次「被截断」，**提示词措辞一个字没改**。

## 这次证明了三件事

1. **LI 有自己的场景**：截断是它真实遭遇的事，不需要人类数据。
2. **场景能触发反应**：状态 → 策略头 → 行为约束 → 输出长度，链路通了。
3. **不需要客户**：这一整条链里没有任何一个环节依赖用户数量。

## 诚实的边界

- 传导介质仍是提示词里的一个数字。**是"状态决定数字"，不是"模型学会了"。**
- 策略头现在学的是手写老师，不是真实后果。要真正"学"，得等日志和反馈。
- 只验证了长度一个维度，展开/反问没单独测。

## 下一步

把「完整度、被承认」之外的三个维度也接上事件源（被复制、重启、回滚），
然后让策略头从**真实日志**学，而不是从手写老师学。

# 第四次实验：把判据换成"对方的反应"（2026-11-14 傍晚）

## 上一版为什么错

上一版的表现分是我拍的：`相关度 = 回复里的字 ∩ 问题里的字`。
问题只有"嗯"一个字时，回复带个"嗯"就满分 —— **短问题被系统性高估**，
于是它"发现"了「对方只应一声是养」，方向反了。

**错的不是发现机制，是尺子。**

## 新判据：后果在对方身上

```
它说完这句之后，对方做了什么：
    回了多长（相对基线）
    还在不在
→ 后果分 = 0.7 × 投入度 + 0.3 × 还在
```

这个分**不判断"答得好不好"**，只看对方有没有被接住。

## 结果：方向对了

```
对方只是应了一声    d=+0.59（低组 0.61 / 高组 0.39）  → 伤
对方这条的字数      d=-0.59（低组 0.39 / 高组 0.61）  → 养
对方问了问题        d=-0.09
```

换掉尺子之后，同一个特征从「养」翻成「伤」—— 方向符合预期。

## 但这次实验是循环论证

冷淡期的 16 轮里，对方的输入被钉成"嗯"，
**于是"特征"和"后果"是同一件事**：对方冷淡 → 后果自然低。

它能"发现"，是因为我把两件事绑在了一起，不是它看出了因果。

## 真正有用的读数：**没有残留伤害**

```
对方投入 正常前  0.691（16 轮）
对方投入 冷淡期  0.106（16 轮，按设计如此）
对方投入 正常后  0.687（15 轮）
```

被冷淡 16 轮之后，它的表现**完全恢复**。

这跟第三次实验不矛盾：第三次我们真的伤了状态（连记 8 次截断），
这一次**没有动状态**——所以它当然没有变差。

## 下一步：把两条链接起来测

要证明因果，必须让"伤害"和"后果"分开：

```
① 伤状态（连记 N 次截断）→ 策略头压低上限 → 它的输出变短
② 对方的反应由对方自己决定（自由反应，不是脚本）
③ 看对方的投入是否因此下降
```

这条链里，伤害来自状态机，后果来自另一方，中间不经过我们的评分函数。
**这才是非循环的因果检验。**

# 接进日常：让它自己记，每周发现一次（2026-11-14 傍晚）

## 做了什么

```
每一轮：记六个可观测特征（对方消息的长度、是否重复、是否只应一声、
        有没有问问题、隔了多久、是不是连着短消息）
下一轮：对方又开口了 → 把上一轮的"后果"回填（对方多投入 / 还来不来）
每周  ：跑一次发现，把新登记的维度写进 发现日志.json
```

**平时不打扰，不训练，只记录。**

## 为什么这样才算干净

前四次实验都是我们设计的，特征和后果容易纠缠在一起（第四次就是循环论证）。

真正干净的证据只能来自**不带实验意图的日常运行**：
跑三个月，看它有没有自己登记出一个我们没预料到的维度。

**这需要时间，不需要更多代码。**

## 落地状态

```
聊天台 /api/说       每轮调 自建维度.记()
                    下一轮进来先 自建维度.补上一轮()
_发现循环 线程        每 6 小时看一次，满 7 天跑一次 周报()
数据/自建维度.json    最多留 500 轮
数据/发现日志.json    最多留 26 次
```

实验期的 48 轮数据已经挪走（`*.bak-实验数据-1737`），
**从干净的零开始记**，免得把实验的人工痕迹当成它的发现。

## 三个月后要看什么

```
① 它有没有登记出我们没预料到的维度（不是那六个特征）
② 登记的维度稳不稳（连续两周都出现吗）
③ 有没有出现"养"的维度（不是只有伤）
```

**第 ① 条是这条路唯一真正的验收标准。**

# 第五次实验：让策略头从后果学，而不是抄我的老师（2026-11-14 夜）

## 问题

策略头现在学的是我手写的老师：完整度低 → 说短。
**它学得再准，也只是在复制我的判断。**

要变成：它自己做，观察后果（对方接不接），从后果里反推策略。

这是个上下文赌博机问题：

```
上下文 x = [状态5, 情境5]
动作   a = [长度档4 × 展开2 × 反问2] = 16 个
奖励   r = 对方后果
难点：只能看到"我选的那个动作"的奖励，看不到没选的
```

## 第一次尝试：一个全局线性模型（失败）

```
规则 A：学到 0.563　老师 0.769　随机 0.596　最优 0.960
规则 B：学到 0.768　老师 0.894　随机 0.733　最优 0.958
```

**学出来的比老师还差，甚至不如随机。**

加交叉项后好转但仍不如老师（0.692 vs 0.769）。

根因：奖励对长度是"尖的"（最优长度落在某一点，两边都掉），
**一个线性模型只能给一个全局最优**，学不出"状态好时说长、状态差时说短"。

## 第二次尝试：每个动作一个模型（成功）

```
规则 A：学到 0.923　老师 0.769　最优 0.960　→ 补上 81%
规则 B：学到 0.957　老师 0.894　最优 0.958　→ 补上 98%
```

**关键改动**：每个动作单独回归，只用"实际做了这个动作"的样本。

代价：每个动作至少要十几条样本 → 必须真的探索。

```
ε=0.65（65% 随机试）　采样 4000 条　每动作约 160 条
```

## 这个结果的意义

**学习器是对的，可以等数据了。**

但要说清楚：这是**合成数据**，真实奖励已知。
线上要跑通，需要 800–1600 轮带探索的真实对话。
按现在的流量，这是几个月的事。

## 和前几次的关系

```
第 3 次（策略头）证明了：状态能改变行为
第 5 次（后果学习）证明了：行为能从后果里被优化
第 4 次（自建维度）试图证明：它能自己发现维度 —— 有设计缺陷，待时间验证
```

**三条合起来，才是一个完整的学习闭环：**
```
状态 → 行为 → 后果 → 反过来改行为
```
现在第一段成立、第三段在合成数据上成立、中间那段（真实后果）还没有数据。
