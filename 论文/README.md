## 两篇论文什么关系

```
机制篇（场景历史叠加）
    ↓ 回答"为什么这么建模、能不能训练"
系统篇（数字分身架构）
    ↓ 回答"在一个真实产品里怎么落地、踩了哪些坑"
```

机制篇更"硬"：它只主张一件事——**场景与历史的叠加是一次带温度的概率检索**，而现代 Hopfield 与注意力等价，所以这件事天然可微、可训练。系统篇更"软"：把四个可计算的量（档案厚度、此刻场景、被想起的历史、内分泌底色）放进一个真人分身产品里，报告案例与教训。

## 核心结论（两篇共用）

> 把「像一个人」拆成四个可计算的量：**档案有多厚、此刻在干什么、这次想起了什么、这几天什么底色**。

## 写作约定

- 实验一律标注为**案例研究**，不称 benchmark；
- 系数、半衰期、分类体系如属工程选择，明确写出"无实证依据"；
- 引用文献时，仅查阅摘要或综述页面的会注明；
- **未做的实验**（如端到端训练）写入"局限"与"未来工作"，不得暗示已完成。
