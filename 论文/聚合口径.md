# 聚合口径：让一万个人的贡献可以被加总

**An Aggregation Schema: Making One Million Individual Contributions Addable**

---

## 摘要

《三层可训练架构》提出 L0/L1/L2 分层：共享"人怎么被事件影响"，私有"他被什么影响过"。

但那篇论文回避了一个工程问题：**每个人贡献的数据，以什么格式才能被加总？**

如果一千个人各自留下"他爸 2019 年去世"这样的文本，它们既不能被聚合，也不能被共享。本文提出一套最小口径，让个体贡献变成**可以相加的参数**：

```
（事件类, 极性, 强度中位数, 半衰期, 触发阈值, 样本数, 置信度）
```

核心设计有五条：

1. **事件类必须封闭**（12 类），否则无法对齐；
2. **只上传聚合参数，不上传任何原文**；
3. **每个参数必须带样本数**，否则单次事件会污染统计；
4. **半衰期从行为反推，不问本人**（自陈不可靠）；
5. **置信度由样本数与方差算出**，低置信度的行不参与训练。

这套口径的价值不在算法，在**可加性**——它决定了这条路能不能从"一个人的实验"变成"一万人的先验"。

**关键词**：数据口径；聚合；联邦学习；隐私；个体差异

---

## 1 问题：现在攒不下来

一个直接的事实：**如果每人贡献的格式不一致，攒再多也加不起来。**

举例，三个用户分别留下：

```
用户 A："我爸去年走了，到现在还会想起"
用户 B："被合伙人坑了二十万，不信人了"
用户 C："被当众说能力不行，记了很久"
```

这三句话，**没有任何办法加总**。它们长度不同、对象不同、时间尺度不同。

要做大规模训练，第一步不是算法，是**让它们变成同一张表的同一行。**

## 2 五个必要条件

### 2.1 事件类必须封闭

开放词表 = 无法对齐。必须有固定的 12 类，每一条真实事件先被归类。

```
丧亲 · 疾病 · 财务损失 · 被背叛 · 被否定/羞辱 · 分离
失业/失去活路 · 被帮助 · 被接纳 · 被认可 · 成家/新生 · 迁移
```

12 类是个折中：太粗（"负面事件"）没有信息，太细（"被亲哥骗钱"）无法聚合。

**分类器可以换，分类表必须稳定。** 否则历史数据作废。

### 2.2 只上传聚合参数，不上传原文

一个人对 A 类的反应，用三个数概括：

```
强度中位数   这类事件后，情绪变化多少（0~1）
半衰期       多久回到基线（小时）
触发阈值     多小的事才动（0~1）
```

**这三个数里没有一个字是他的私事。**

"丧亲类 → 强度 0.78，半衰期 41 天"——这句话可以公开，因为它描述的是**一类反应**，不是一次经历。

### 2.3 每个参数必须带样本数

一个人可能只经历过一次丧亲。**一次样本算出来的半衰期，是噪声。**

所以每一行必须带 `n`，且 `n < 3` 的行不参与 L0 训练，只用于 L2 校准。

### 2.4 半衰期从行为反推，不问本人

问"你多久能走出来"得到的是**他希望的自己**，不是他实际的样子。

正确做法：**从他的情绪轨迹反推。**

系统每一轮都在算情绪 S（判情模块，默认半衰期 6 小时）。一次重大事件后，S 的衰减曲线可以被拟合：

```
S(t) = S₀ · 2^(−t/τ)
```

对每个人的轨迹做拟合，得到**他自己的 τ**。这是行为数据，不是自陈。

### 2.5 置信度由样本数与方差算出

```
置信度 = f(n, 方差)
```

同一个人同一类事件，若三次反应差异巨大（方差高），说明这类事对他的影响不稳定，置信度应低。

**低置信度的行不是"少用"，是"不用"**——否则噪声会被当作个体差异学进 L0。

## 3 具体口径

```json
{
  "事件类": "丧亲",
  "极性": -1,
  "强度中位数": 0.78,
  "强度方差": 0.04,
  "半衰期_h": 984,
  "触发阈值": 0.15,
  "样本数": 1,
  "置信度": 0.31,
  "版本": "口径-1"
}
```

一个人贡献 12 行（每类一行），加上他的七个旋钮值，总共不到 1 KB。

**一万个人，不到 10 MB。**

这个体积是可训练的，也是可公开的——只要每一行都满足 §2.2。

## 4 这套口径能不能被反推

必须回答的问题：**从"丧亲 → 0.78 / 984h"能不能反推出"他爸去世了"？**

不能，因为：

- 强度 0.78 可以是丧父、丧母、丧偶、丧子；
- 半衰期 984 小时（41 天）是一类人的典型值，不是某个人的标识；
- 一行数据不含时间、地点、关系细节。

**但如果加时间戳**（"2026-03 有一行丧亲，强度 0.78"），范围就缩小到"那个月发生了一次丧亲"。

所以必须加一条：**时间戳模糊到季度**，且**不单独发布任何一行**——只发布聚合结果。

## 5 隐私的边界在哪

| 粒度 | 能不能公开 |
|---|---|
| 原文 | ❌ 绝不 |
| 单行参数 + 时间戳 | ❌ 不可（范围太小） |
| 单行参数（无时间戳） | ⚠️ 谨慎 |
| 12 行参数（一个人的全部） | ⚠️ 谨慎（准标识） |
| 一万人的聚合统计 | ✅ 可以 |

**结论：个体贡献只进训练，不对外发布。对外只发布聚合后的模型。**

## 6 什么时候这一行能进 L0

三条同时满足：

```
① n ≥ 3（有足够样本）
② 置信度 ≥ 0.5
③ 该事件类在全局样本里 ≥ 100 人（避免某一类被少数人主导）
```

不满足的，只用于 L2 校准（他自己的七个旋钮），不进共享训练。

**这条规则的意义**：它让"数据不够"变成"数据分层"，而不是"数据无用"。

## 7 与 LLM 训练数据的对照

| | LLM | 本文 |
|---|---|---|
| 一个样本 | 一段文本 | 一行参数 |
| 样本量 | 万亿 token | 一万行 |
| 学什么 | 语言的统计结构 | 事件→反应的统计结构 |
| 隐私 | 来自公开网页 | 来自行为，聚合后无内容 |
| 训练一次的成本 | 千万美元 | 可忽略 |

**这不是"小号的 LLM 训练"，是另一种东西：用统计形状代替文本。**

## 8 局限

1. 12 类是否足够，未验证。
2. 从行为反推半衰期，需要足够密的情绪轨迹；冷启动用户没有。
3. 一个人的 12 行参数仍可能是准标识（罕见事件类 + 极端值）。
4. 本文只给口径，没有实现聚合与训练。

## 9 结论

**大规模训练的前提不是模型，是口径。**

只要一千个人贡献的数据不能变成同一张表的同一行，攒十年也没用。

而这套口径的核心只有一句话：

> **贡献参数，不贡献故事。**
