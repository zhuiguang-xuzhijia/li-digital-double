# 三模块训练流程：历史 / 场景 / 想象

> 设计稿 v0.1。目标：把"事件确定、态度不确定"落成一套可训练的管线。
> 原则：**客观进索引，主观进排序；事实落盘，投影现算。**

---

## 零、数据形状

### 事实（历史的最小单位）

```
e = { 时, 主体, 动作, 受事, 场所, 在场者, 结果, 数量, 来源, 可验证 }
```

全部字段**客观可验证**，不含"灾难/失去/冲突"这类评价。

### 场景

```
s_客观 = { 此刻时间, 地点, 正在做什么, 能聊多久, 在场者 }
s_主观 = { 需求, 情绪 S, 皮质醇/多巴胺/睾酮 }      ← 只进 query，不进 key
```

### 想象

不是数据，是**生成物**：把检索到的历史片段替换时间槽、拼接，得到一个"没发生过但可能发生"的序列。

---

## 一、模型骨架（五个部件）

```
             ┌──────────────┐
  事实 e ───▶│  事件编码器   │──▶ h_e ∈ R^64
             └──────┬───────┘
                    │
             ┌──────▼───────┐
             │ 1D 卷积(多尺度)│──▶ 局部模式 + 上下文
             └──────┬───────┘
                    │
             ┌──────▼───────┐
             │  VQ 码本 K=64 │──▶ 离散记忆 token（可审计）
             └──────────────┘

  场景 s ───▶ 场景编码器 ──▶ q ∈ R^64
                              │
                    ┌─────────▼──────────┐
                    │ 检索：内积 + 时间衰减 │──▶ top-2（一近一远）
                    └─────────┬──────────┘
                              │
                    ┌─────────▼──────────┐
                    │ 差值/投影头 P       │──▶ 威胁/失控/被帮/羞耻/时光感
                    └─────────┬──────────┘
                              │
                    ┌─────────▼──────────┐
                    │ 想象解码器 D        │──▶ 反事实序列 → 再投影 → 决策
                    └────────────────────┘
```

## 二、训练分五阶段

### Stage 0：事实结构化（规则 + 弱监督）

**做什么**：把文本历史拆成客观字段。

```
"九八年发大水，屋子冲垮了，一家人挤在堤上"
→ { 时:1998, 主体:[水], 动作:冲垮, 受事:屋子, 在场者:[我,家人],
    场所:家→堤上, 结果:住所损毁, 可验证:高 }
```

**损失**：字段级交叉熵（在有标注的子集上）

```
L0 = Σ_字段 CE(预测字段, 真字段)
```

**数据需求**：几百条人工标注的事实（**这是最贵的一步**）

**产出**：结构化事实表 + 抽取器

**为什么排第一**：后面所有阶段都吃这个格式。抽不出就留 None，**不许模型猜**。

---

### Stage 1：事件编码 + 码本（自监督，掩码重建）

**做什么**：在时间线上遮住若干事件，用上下文 + 码本 token 把它猜回来。

```
输入：e₁ … eᵢ₋₁ [MASK] eᵢ₊₁ … e_T
输出：被遮事件的客观字段
```

**损失**：

```
L1 = L_mask + β·L_commit + γ·L_codebook
     │         │              │
     │         │              └─ 码本项：让 e 靠近选中码字（VQ-VAE 原式）
     │         └─ 承诺项：让编码器别乱飘
     └─ 字段重建交叉熵
```

**数据需求**：几千条事件序列（现在 147 条，**必须先合成扩充**）

**产出**：事件编码器 + 记忆码本（K=64 个"记忆原子"）

**失败模式**：**码本坍塌**（所有事件映射到同一个码字）。
对策：EMA 更新码本 + 死码重启 + 每 500 步检查码本使用熵。

**为什么用离散**：审计。用户要能问"为什么想起这件事"，答案得是"37 号记忆原子（连续倒霉）"，而不是"某个 64 维向量"。

---

### Stage 2：检索（有监督，对话数据）

**做什么**：给定场景，从某人的历史库里选出该被想起的条目。

```
score(e) = ⟨W_q·s, W_k·h_e⟩ · φ(Δt)      φ(Δt)=exp(−Δt/τ)
p = softmax(β·score)
```

**标签从哪来**（关键）：不用"回话里提到的词"这种主观标签，改用**客观字段重合**：

```
正样本 = 与该轮下一句"共享客观字段最多"的历史条目
       （共享动作/受事/在场者，而不是共享情绪词）
```

**损失**：

```
L2 = −log p(正样本) + λ·max(0, m − p(正) + p(最难负样本))
```

**数据需求**：几百到几千轮对话

**产出**：W_q, W_k, τ, β

**为什么用客观字段做标签**：上一版论文里用"回话反推"，结果是主观标签污染了索引。改用客观字段，标签本身就干净。

---

### Stage 3：差值 / 投影（有监督，情绪标注）

**做什么**：拿检索到的 **两条**，算它们的"差"，产出情绪与意义。

```
Δ = [e_近 − e_远, 时间跨度, 状态变化]
意义向量 m = P(Δ, s)   →  {威胁, 失控, 被帮, 羞耻, 时光感}
```

**损失**：多任务回归 + 分类

```
L3 = Σ_维度 MSE(预测, 标注) + CE(是否触发想象)
```

**数据需求**：这一步需要**人给情绪打标**，最贵也最主观。
冷启动办法：先用 `判情.py` 那套规则生成弱标签，再人工校正一小批。

**产出**：投影头 P

**为什么必须有两条**：单条只能"重现"，两条才能"比较"。**差值是情绪的源头。**

---

### Stage 4：想象（自监督 + 反事实）

**做什么**：把历史片段的时间槽替换、重新拼接，预测"如果这样会怎样"。

```
训练对：
  真实：他那天没去 → 之后的关系
  反事实：他那天去了 → 预测之后的关系
损失 = 预测误差 + 判别器（这个想象是否可能）
```

**损失**：

```
L4 = ‖预测 − 真实‖ + CE(判别器(想象), 标签=不合理/合理)
```

**数据需求**：可以**自己造**——用真实序列做"改了时间槽"的负样本

**产出**：想象解码器 D

**为什么最后做**：它依赖前三阶段的产物（事实、码本、检索、投影）。前面不稳，想象就是胡编。

---

### Stage 5（可选）：端到端微调

用最终回话质量做奖励，微调检索与想象。采样用 Gumbel-Softmax 保持可导。

```
L5 = −E[奖励(回话)] + KL(策略 ‖ 前一阶段)
```

**没有几百条以上的人类评分之前，不要做这一步。**

---

## 三、推理流程（一句话怎么走完）

```
① 编码场景：客观 → q_obj；主观 → q_sub
② 客观召回：按字段硬匹配（施事/受事/场所/时间窗）→ 候选集
③ 主观排序：用 q_sub 对候选打分 → softmax
④ 取两条：最相似的一条 + 差异最大的一条   ← 关键
⑤ 投影：算差值 → 情绪/意义
⑥ 判断：情绪强度 > 阈值 且 与当前目标相关 → 触发想象
⑦ 想象：替换时间槽 → 预测情绪 → 决策
⑧ 生成：把两条事实的**原文** + 情绪标签拼进提示词（喂文字，不喂向量）
```

**第 ④ 步和现在实现的区别**：现在是"取最像的 top-2"，新方案是"**最像的一个 + 差异最大的一个**"。
因为——**要产生"时光荏苒"，必须有第二个时间点。**

---

## 四、评测方案

| 阶段 | 指标 | 说明 |
|---|---|---|
| Stage 0 | 字段抽取 F1 | 客观字段，可自动算 |
| Stage 1 | 掩码重建准确率 + 码本使用熵 | 熵太低 = 坍塌 |
| Stage 2 | hit@1 / MRR | 分"同场景"和"跨场景"两组 |
| Stage 3 | 与人类情绪评分相关性 | 这是唯一需要人的地方 |
| Stage 4 | 人类判别"像不像他会想的" | 二选一强制选择 |
| 生成 | 句长分布 / 口头禅频率 / AI 味盲评 | 与真人语料比分布距离 |

**对照组**：随机、手工权重（现线上方案）、无时间衰减、无差值头。

## 五、现实约束（必须写在纸上）

```
当前数据      147 条事件、23 轮对话
Stage 0       可以开始（规则 + 小批标注）
Stage 1       需要合成数据先跑通，真实数据不够
Stage 2       需要几百轮真实对话 → 目前做不到
Stage 3       需要人工情绪标注 → 最贵
Stage 4       可以自造数据，但意义有限
Stage 5       不可做
```

**所以现实路径是：**

```
先做 Stage 0（结构化）→ 用规则跑通全链路 → 
数据够了再替换 Stage 2 的检索权重 → 再替换 Stage 3 的投影
```

**不推翻现有系统，而是把它替换成"可训练版本"。** 现在线上那套手工权重，就是 Stage 2 的规则基线。

---

## 六、最容易翻车的四个点

1. **码本坍塌** → 所有历史变成一个 token，检索失效
2. **时间衰减过强** → 十年以上的事全部压死，"想不起小时候"反而更假
3. **差值头退化成常数** → 总是输出"中等情绪"，因为标注分布本身就偏中
4. **想象变陈词滥调** → 解码器学的是平均，生成的是"所有人都会这么想"

**第 4 点最麻烦**：想象本质上是在做平均，而不像人——人的想象是**被具体事件绑定的**。缓解办法是把检索到的两条事实作为**硬约束**喂进去，而不是让解码器自由生成。
