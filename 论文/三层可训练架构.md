# 从大集合到个人：数字生命的三层可训练架构

**From Aggregate to Individual: A Three-Tier Trainable Architecture for Digital Lives**

---

## 摘要

为**单个真人**训练一个数字分身，在数据上是不可能的：一个人的一生只留下几十到几百条可提取的记忆，而要从未标注数据中学出"什么该被想起"，所需参数量远大于样本量。

本文提出分层方案：把"人怎么被事件影响"这一**跨人稳定的结构**，与"他被什么影响过"这一**个体内容**分开。

```
L0  基础层：全人类的评价先验        —— 跨人数据训一次，所有人共享
L1  类型层：文化/年龄/职业/阶层先验  —— 群体数据，几十个人群包
L2  个体层：记忆 + 七个标量旋钮      —— 每个人自己的几十条数据
```

关键论证有三条：

1. **可共享的是什么**：事件→情绪的映射、时间衰减形状、事件模式检测、差值→情绪的机制。这些属于人类共有的评价结构（appraisal theory），不是个人隐私。
2. **必须私有的是什么**：具体记忆、评价函数的参数偏移、语言指纹、关系网络。**记忆不出本地**是这类产品的底线。
3. **个体层不是一个小模型，是七个旋钮**（羞耻敏感度、威胁放大、时间衰减速度、归因倾向、差值阈值、对抗倾向、亲密阈值）。七个数字即可区分两个人的"感受方式"，且可解释、可回滚、几十条数据即可拟合。

本文同时给出**判死刑的验证实验**：用一个最小 L0 做 zero-shot 迁移，若与真人反应的相关性低于 0.3，则说明个体差异压倒共性，整条路线需要重新设计。该实验成本约一周。

**关键词**：数字生命；个性化；分层训练；评价理论；联邦学习；人格建模

## 1 引言

### 1.1 一个算术问题

想给某个人做一个会像他一样反应的分身，第一反应是"收集他的数据，训一个模型"。

算一下就知道不成立：

```
一个人的可提取记忆：      10² ~ 10³ 条
学"什么该被想起"的参数量：10⁴ ~ 10⁶
```

样本量比参数量小两到四个数量级。**这不是数据不够的问题，是维度不匹配。**

### 1.2 但有一层是可以学的

人对事件的反应并不全是私人的。"被当众否定会难受"、"多年不见会生疏"、"有人拉一把会记很久"——这些是**跨人稳定**的。

心理学把它叫**评价（appraisal）**：情绪不来自事件本身，而来自个体对事件的评价（目标相关性、应对潜力、归因）。而评价的结构，是人类的共同遗产。

**所以：把"怎么感受"学到共享层，把"感受什么"留在个人层。**

### 1.3 与 LLM 的类比

| | LLM | 本文 |
|---|---|---|
| 通用能力 | 预训练语料 | L0：人类的评价先验 |
| 领域适配 | 领域微调 | L1：人群包 |
| 个人适配 | LoRA / prompt tuning | L2：七个标量 |
| 适配参数量 | ~0.1% | ~0.001% |
| 适配数据量 | 千条 | **几十条** |

**类比成立的前提是 L2 足够小。** 如果个体层要学几万个参数，这条路就退回起点。

## 2 相关工作

### 2.1 人格的跨情境结构

**CAPS**（Mischel & Shoda, 1995）主张人格的稳定部分是 **if（情境）then（行为）** 的签名，而非跨情境一致的平均行为；**Whole Trait Theory**（Fleeson）进一步把特质理解为**状态的概率分布**。

这两条支持"共享结构、个体化参数"的分层：结构是 if-then 的连接方式，参数是连接的强度。

**Persona-CAPS**（Liu et al., EMNLP 2026）已把这套结构搬到 LLM 上：从公开经验取样（ESM）数据挖掘 if-then 条目，按情境检索。这是本文最接近的工程先例，也证明了**跨人语料可以支撑一个可复用的性格底座**。

### 2.2 评价理论

Lazarus 与 Scherer：情绪由**评价**产生，评价包含目标相关性、应对潜力、归因、规范性等成分。这些成分是跨人共享的**维度**，而它们在个体身上的**权重**不同——这正是 L0 与 L2 的分工。

### 2.3 参数高效适配

**LoRA**（Hu et al., 2021）表明，冻结主干、只训练低秩增量，即可在很小参数量下完成适配。本文的 L2 比 LoRA 更激进：不是低秩矩阵，而是**七个标量**。

### 2.4 隐私保护训练

**FedAvg**（McMahan et al., 2017）提出在数据不出本地的前提下聚合模型更新。本文采用同样的立场：**记忆不出本地，只上传评价函数的更新**。

## 3 三层架构

### 3.1 L0：基础层

```
输入：事实的客观字段（时/主体/动作/受事/场所/在场者/结果）+ 场景的客观字段
输出：评价向量（威胁、失控、被帮、羞耻、时光感…）
训练：跨人（事件, 场景, 反应）三元组，万~十万级
```

**L0 学的是"结构"，不是"数值"**：它应预测"这件事会触发羞耻这类情绪"，而不是"羞耻强度是 0.7"。强度留给 L2。

### 3.2 L1：类型层

在 L0 之上按群体微调：文化、年龄段、职业、阶层。产出是**几十个人群包**，选一个作为个体适配的起点。

### 3.3 L2：个体层

**七个标量**（可解释、可回滚）：

| 旋钮 | 含义 | 观测方式 |
|---|---|---|
| 羞耻敏感度 | 被否定时多痛 | 对话中被纠正后的反应强度 |
| 威胁放大系数 | 坏消息的影响倍数 | 负面事件后的情绪衰减曲线 |
| 时间衰减速度 | 多久会淡 | 同一事件在不同时间点的提及频率 |
| 归因倾向 | 内 / 外 | 谈及失败时的主语 |
| 差值阈值 | 多小的落差才动情 | 触发"感慨"类表达的条件 |
| 对抗倾向 | 被顶了顶回去还是忍 | 冲突场景的回应长度与强度 |
| 亲密阈值 | 多熟才肯说私事 | 首次出现私密信息的轮次 |

**为什么是标量而不是向量**：七个数字可以被审计（"他为什么这么反应？因为羞耻敏感度 0.8"），可以被回滚（改回 0.6），可以在几十条数据内拟合。

## 4 什么共享，什么私有

| 层 | 内容 | 共享 | 依据 |
|---|---|---|---|
| 事件→情绪映射 | 被当众否定→羞耻 | ✅ | 评价理论 |
| 时间衰减形状 | 遗忘曲线 | ✅ | 跨人相似 |
| 事件模式检测 | "连续倒霉" | ✅ | 叙事结构 |
| 差值→情绪 | 比较产生落差感 | ✅ | 机制，非内容 |
| 想象的合理性先验 | 什么算"可能" | ✅ | 社会常识 |
| 具体记忆 | 他父亲哪年去世 | ❌ | 身份 |
| 参数偏移 | 同样被骂，他更痛还是更无所谓 | ❌ | 性格 |
| 语言指纹 | 口头禅、句长 | ❌ | 嗓音 |
| 关系网络 | 谁欠谁 | ❌ | 社会位置 |

**原则：共享规则，私有内容。**

## 5 数据

| 来源 | 规模 | 质量 | 难度 |
|---|---|---|---|
| 经验取样法（ESM）公开数据 | 万级 | 高（真实、即时） | 中 |
| 心理学 if-then 实验数据 | 千级 | 高 | 中 |
| 访谈 / 口述史 | 万级 | 中 | 低 |
| 剧本 / 小说 | 百万级 | 低（作者视角） | 低 |
| LLM 合成 | 无限 | **危险** | 低 |
| 真实对话（本系统） | 23 轮 | 高 | 慢 |

**合成数据的陷阱**：用 LLM 生成"普通人被骂会怎样"，得到的是**模型认为的平均人**。用它训练 L0，会系统性抹平个体差异——恰好摧毁我们要建模的对象。

因此合成数据只能用于**验证管线可跑**，不能用于学习个体差异。

## 6 隐私架构

```
方案 A：共享表示
  所有人的事件映射到同一语义空间 → 可跨人比较，但记忆须上传   ✗

方案 B：共享函数
  记忆留本地，只上传评价函数的更新 → 隐私友好，但无法跨人对比  ✓
```

本文选 B。实现路径：本地计算梯度 → 差分隐私 → 聚合（FedAvg 式）。

**对真人分身产品，记忆不上传是底线，不是可选项。**

## 7 一个能判死刑的验证

整条路线成立与否，取决于一个问题：

> **跨人学到的评价先验，能否在没见过的人身上产生有意义的预测？**

实验设计（成本约一周）：

```
Step 1  用公开 ESM 数据或合成数据，训练一个最小 L0
        （输入：事件客观字段 + 场景；输出：情绪维度）

Step 2  在本系统 147 条真实历史上做 zero-shot 测试（不微调）

Step 3  计算预测与真人反应的相关性
```

判据：

```
相关 > 0.3   → 共享层有信号，继续
相关 ≈ 0     → 个体差异压倒共性，路线需重设计
```

**先做这个，再谈架构。** 如果相关性为零，任何精巧的分层都只是把噪声分了三层。

## 8 风险

1. **个体差异压倒共性**：L0 退化为无用的平均值。
   对冲：L0 输出分布而非点；方向共享、强度个人化。

2. **合成数据污染**：模型的平均人取代了真实的人。
   对冲：合成仅用于管线验证；个体差异只从真实数据学。

3. **七个旋钮不够**：真实的人格差异可能需要几十维。
   对冲：旋钮可扩展，但每加一个都要能观测、能解释、能回滚。

4. **数据获取的伦理成本**：真实的"事件—反应"数据极其敏感。
   对冲：去标识化、本地化、只学结构不学内容。

---

## 9 结论

**一个人不够训，但所有人加起来够。**

这条路线成立的前提是两个分离：

- **把"人怎么被事件影响"（结构）与"他被什么影响过"（内容）分开**；
- **把 L2 小到七个标量**，使它能在几十条数据内被校准。

如果这两个前提成立，数字生命就不是"每个用户训练一个模型"的奢侈品，而是**一次基础训练 + 每人七次校准**的工程问题。

如果前提不成立，这个领域就仍停留在"写人设提示词"的阶段——而那正是我们要离开的地方。
