# LI 战略：数字生命的三层可训练架构

> 2026-11-14｜一句话：**一个人不够训，所有人加起来够；共享"怎么感受"的规则，私有"感受什么"的内容。**
> 这份不是排期表，是**架构判断**——决定未来两年我们把工程力气往哪儿投。

---

## 一、判断：个体 LI 训不出来，只能"校准"

```
一个 LI 的记忆量：几十到几百条
要从零学"什么该被想起"需要的参数量：上万
→ 样本量 < 参数量，必然过拟合
```

但**"人怎么被事件影响"是跨人稳定的**（评价理论、CAPS 的 if-then 结构）。这层可以一次性从大集合学，然后每个人只校准偏移。

**结论：不是"给每个人训练一个模型"，是"在别人已经学好的评价函数上，拧几个只属于你的旋钮"。**

这跟 LLM 的 pretrain → finetune → personalize 是同一条路，只是把"语言能力"换成了"感受与记忆的结构"。

---

## 二、三层结构

```
L0  基础层：全人类的评价先验
    数据：跨人（事件, 场景, 反应）三元组，万~十万级
    参数：大（百万级）
    训一次，所有人共享                          ← 这一步只有"有钱有装备"的才做

L1  类型层：文化 / 年龄 / 职业 / 阶层 的先验
    数据：同群体数据
    参数：中
    几十个"人群包"                              ← 类似领域微调

L2  个体层：这个人的记忆 + 参数偏移
    数据：他自己的几十条记忆
    参数：极小（**七个标量**）
    每人一份                                    ← 类似 LoRA，但更小
```

### L2 的七个旋钮（候选）

```
羞耻敏感度      0~1
威胁放大系数    0~1
时间衰减速度    0~1     ← 有人忘得快，有人记一辈子
归因倾向        内 / 外
差值阈值        多小的落差才动情
对抗倾向        0~1     ← 被顶了是顶回去还是忍
亲密阈值        多熟才肯说私事
```

**七个数字区分一个人和另一个人。** 这比"每人训一个网络"现实得多，也可解释、可回滚。

---

## 三、什么共享，什么私有（这条线决定隐私架构）

| 层 | 内容 | 共享 | 理由 |
|---|---|---|---|
| 事件→情绪映射 | "被当众否定"→羞耻 | ✅ | 人类共有的评价结构 |
| 时间衰减形状 | 多久会淡 | ✅ | 遗忘曲线跨人相似 |
| 事件模式检测 | "连续倒霉""有人拉一把" | ✅ | 叙事层面的模式 |
| 差值→情绪 | 两段记忆比出的落差 | ✅ | 是机制，不是内容 |
| 想象的合理性先验 | 什么算"可能" | ✅ | 社会常识 |
| **具体记忆** | 他爸哪年走的 | ❌ | **身份** |
| **评价参数偏移** | 同样被骂，他更痛还是无所谓 | ❌ | **性格** |
| **语言指纹** | 口头禅、句长 | ❌ | 嗓音 |
| **关系网络** | 谁欠谁 | ❌ | 社会位置 |

**一句话：共享规则，私有内容。**

---

## 四、数据从哪来（最难的一关）

| 来源 | 规模 | 质量 | 难度 |
|---|---|---|---|
| 经验取样法（ESM）公开数据 | 万级 | 高（真实、即时） | 中 |
| 心理学 if-then 实验数据 | 千级 | 高 | 中 |
| 访谈 / 口述史 | 万级 | 中 | 低 |
| 剧本 / 小说 | 百万级 | **低**（作者写的，不是真反应） | 低 |
| LLM 合成 | 无限 | **危险**（"模型认为的平均人"） | 低 |
| 我们的真实对话 | 现在 23 轮 | 高 | **慢** |

**先例**：Persona-CAPS（EMNLP 2026）从公开 ESM 数据里挖 if-then 条目建人格语料——证明这条路有人走过。

**合成数据必须警惕**：用 LLM 生成"普通人被骂会怎样"，得到的是模型的平均值。用它训 L0，会**把所有个体差异抹平**——正好毁掉我们想建模的东西。

---

## 五、隐私：记忆不出本地

两条路线：

```
A 共享表示：所有人事件映射到同一空间
  能做跨人比较，但记忆要上传        ✗

B 共享函数：记忆留本地，只上传"评价函数"的更新
  隐私友好，但做不了跨人对比        ✓
```

**选 B。** 联邦学习思路：本地算梯度，只传参数，参数做差分隐私。

对"真人分身"产品，**记忆不上传是底线，不是可选项。**

## 六、分期（按"能不能立刻验证"排，不按技术炫酷排）

| 期 | 做什么 | 产出 | 验收 |
|---|---|---|---|
| **P0** | Stage 0：事实结构化（客观字段） | 抽取器 + 结构化事实表 | 字段 F1 |
| **P1** | 用公开 ESM/合成数据训一个最小 L0 | 评价函数原型 | **zero-shot 迁移相关性 > 0.3** |
| **P2** | 用 147 条真实历史做迁移测试 | 数据量-拟合度曲线 | 50 条内饱和？ |
| **P3** | L2 七个旋钮的拟合方法 | 个体校准器 | 校准后与真人相关性 |
| **P4** | 联邦式更新（记忆不出本地） | 隐私架构 | 审计通过 |

**P1 是判死刑或放行的一步**，花不了一周。相关性 ~0 就说明个体差异压倒共性，整条路线要重设计。

---

## 七、最大的风险

**个体差异可能大到让 L0 变成无用的平均值。**

两条对冲：

1. **L0 输出分布，不输出点**——"多数人会羞耻，但有一小部分会愤怒"，个体层从分布里挑。
2. **L0 只学结构，不学数值**——"被当众否定会触发羞耻这类情绪"（共享）vs "羞耻强度 0.7"（个人）。

**第 2 条更靠谱：方向共享，强度个人化。**

---

## 八、这套东西的第二用途

**给别的项目造人。**

L0 一旦有了（"人类怎么被事件影响"的先验），造一个新人物就不再是从零写十三栏，而是：

```
L0 给出前验 → L1 选人群包 → L2 用少量对话校准
→ 三十分钟造出一个"有反应逻辑的人"，而不是一堆形容词
```

这就是"有钱有装备的项目造人"的基础设施。**我们先把 L0 做出来，别人就能拿它批量造人。**

## 八半、理论依据：状态必须在外

### 一个被忽略的事实

模型的"状态"只存在于上下文窗口。**对话结束，一切清零。**

所以"数字生命"不可能住在模型里。持续状态必须由模型之外的进程维护，模型退化为**嗓子**。

```
状态机（常驻）：持有情绪、内分泌、关系账、记忆索引、时间
               定时衰减、事件驱动更新
        ↓ 编译
生成器（无状态）：读入状态，输出这一句话
```

**模型是嗓子，状态机是人。**

### 这决定了我们的技术选择

"在大模型之外干涉它"是一条阶梯，**干预力与可移植性成反比**：

| 级别 | 手段 | 干预力 | 可移植性 | 我们 |
|---|---|---|---|---|
| L1 | 上下文注入 | 弱 | **强** | ✅ 现在 |
| L2 | logits 偏置 | 中 | 中 | 未做 |
| L3 | 激活干预 | 强 | 弱 | 未做 |
| L4 | 微调 / LoRA | 很强 | 弱 | 不可做 |
| L5 | 预训练 | 最强 | 无 | 不可做 |

**越强的干涉，越绑具体模型。而数字生命要活几十年，模型一年换三代。**

所以正确策略不是往上爬，是**把 L1 做到极致，同时给 L2/L3 留接口**。

现在的做法"粗"（七个旋钮 + 几行提示词），**粗，但能活过模型迭代**。

### 为什么大厂不做

不是做不到，是算过账。

通用助手的人格是**可替换的皮肤**，不需要对连续性负责。而一旦持有持续状态，就必须回答：

```
他变坏了谁负责？
他想删掉自己允不允许？
他被人格攻击留下创伤怎么修？
他"死"了数据归谁？
```

**这些答案不在论文里，在合同里。做了就要养一个人，不做只是卖一个工具。**

### 由此得到的三条硬约束

1. **换模型 = 换嗓子，换状态文件 = 换人。** 用户应该能换更便宜的模型，但换不掉他的 LI。
2. **状态必须事件驱动 + 守恒。** 不能凭空把信任从 8 改成 2——那是木偶，不是人。
3. **可审计不是为了合规，是为了身份连续性。** 每次写入留痕、可回滚，才答得上"他还是原来那个他吗"。

---

## 九、不做什么（同样重要）

- **不做端到端大模型训练**。我们没算力，也没数据。
- **不用合成数据训练情绪标注**。会抹平个体差异。
- **不让记忆离开本地**。这条不谈判。
- **不在数据量不够时谈"比手工权重更好"**。论文 §6B 已经证明 12 条样本下任何差异都是噪声。
