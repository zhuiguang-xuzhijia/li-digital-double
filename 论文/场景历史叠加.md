# 场景—历史叠加的可概率化：一个可微的联想记忆框架

**Scene–History Superposition as Probabilistic Retrieval: A Differentiable Associative Memory Framework**

---

## 摘要

人想起什么，取决于他此刻身处什么场景。同一个问题，在雨天和被骂之后，牵出的是两段完全不同的往事。这一现象通常被描述为"联想"，却很少被写成可计算的机制。

本文主张：**「场景—历史叠加」是一次带温度的概率检索**，因而与神经网络的注意力机制在数学上同构。既然同构，它就天然可微，反向传播能一路走到参数。

论证分四步：

1. **行为层**：记忆提取是随机采样而非查表（SAM / MINERVA 2），且提取概率随编码—提取情境的匹配而变（编码特异性）；
2. **表征层**：情境是结构化表征（情境模型、事件分割），而结构化表征可由**向量绑定与叠加**编码（VSA/HRR、超维计算）；
3. **训练层**：语义与情境表示可由**自监督**学得（分布式语义、掩码语言模型）；
4. **计算层**：现代 Hopfield 网络的更新规则 `ξ = X·softmax(βXᵀξ)` 与 Transformer 注意力**等价**——因此"按概率取回记忆"正是神经网络的内置原语，而非外部插件。

四步合起来给出一个结论：**把场景与历史表示为向量、用 softmax 计算提取概率、按概率抽样，是一个与神经网络同构的最小机制**；它既解释行为层的"这次想起这件事"，也允许端到端训练。

我们给出该框架的**符号化离散近似**并在真实对话系统中做了可行性验证：同一角色的同一批历史，在"下雨"线索下抽出水灾记忆、在"儿子"线索下抽出婚事记忆（统计上 88.5% vs 30%）。本文同时给出一个**零依赖的可训练原型**（约 250 行、手写反向传播）：在同一合成任务上，损失从 2.36 降至 0.12，检索准确率从 0%（随机猜 12%）升至 100%。该原型证明的是这个形式确实可训练，**不是**它已优于手工权重——后者仍需真实语料上的实验。

**关键词**：联想记忆；概率检索；注意力机制；向量符号架构；情境模型；可微记忆

## 1 引言

### 1.1 一个日常现象，缺一个形式化

你问一个人"最近怎么样"。下雨了，他说起十几年前那场水；提起孩子，他说起儿子结婚那年。**问句没变，答话的素材变了。**

常识把它叫作"联想"。但"联想"不是一个可计算的机制——它没有参数、没有损失函数、不能训练。心理学有大量关于联想与提取的研究（§2），机器学习有大量关于注意力与检索的研究（§3），但两者的接缝处常被一句"类似"带过。

本文试着把这条接缝补上，并且只主张一件事：

> **场景与历史的叠加，可以被形式化为一次带温度的概率检索；因此它天然是一个可微模块。**

如果这个主张成立，那么"人为什么此刻想起这件事"就不再是不可建模的黑箱，而是一个有参数、可优化、可解释的对象。

### 1.2 为什么要"可训练"

手工设计规则（如"下雨 → 灾难标签 → 加权"）能做出可用效果，但有两个天花板：

1. **标签是人定的**。"下雨"该连到"灾难"还是"潮湿"，取决于具体的人；
2. **权重是人调的**。为什么是 0.8 而不是 0.6，没有依据。

若该机制与注意力同构，则它可以用同一套工具训练：把场景与历史嵌入同一向量空间，用**下一句**作为监督信号，让"该被想起的那段"获得更高概率——**这就是反向传播**。

### 1.3 贡献

1. 给出「场景—历史叠加 = 概率检索」的形式化，并论证其与注意力机制的同构（§4）；
2. 给出**可微化**的具体路径：向量化、绑定、软采样（Gumbel-Softmax）、训练目标（§5）；
3. 给出该框架的**符号化离散近似**及真实系统上的可行性验证（§6）；
4. 诚实报告未做端到端训练这一根本局限（§7）。

## 2 行为层证据：提取是概率的，且随情境变

### 2.1 提取是采样，不是查表

**SAM（Search of Associative Memory）** 与 **MINERVA 2** 是两类经典的随机记忆模型：给定线索，它们输出的是各记忆被提取的**概率**，重复提取会产生变异。这与"最相似项唯一确定"的检索模型形成对照。

**海马重放（replay）** 被广泛解释为对经历的**采样**，服务于泛化与索引构建。

### 2.2 提取概率随情境变

**编码特异性原则**（Tulving & Thomson）指出：提取效果取决于**提取线索与编码情境的匹配程度**。经典的水下/陆地实验表明，在同一环境中编码与提取的记忆更好；近期在虚拟现实中的检验亦支持这一原则。

**这两条合起来，恰好是"场景—历史叠加"的行为学定义**：场景不是背景，而是**改变提取概率的变量**。

---

## 3 表征层证据：情境可向量化，叠加是运算

### 3.1 情境是结构化的

**情境模型（situation model）** 研究认为，理解一段经历时，人构建的是关于"谁在哪里对谁做了什么"的结构化表征，而非表层序列。

**事件分割理论（Event Segmentation Theory）** 进一步指出：人会在**预测误差升高**处切分事件边界——"场景"不是预先给定的，而是动态生成的功能单元。

### 3.2 结构化表征可以用向量运算实现

**VSA / HRR（Vector Symbolic Architecture / Holographic Reduced Representations）** 证明：用**绑定**（逐元素乘或循环卷积）与**叠加**（加法）两个运算，即可在固定维度向量中编码"角色—填充"结构，并可解码。**超维计算**在更高维上使用类似运算完成分类与推理。

这意味着：

```
场景 s = Σ_i w_i · v(feature_i)          # 叠加
历史 m = v(主体) ⊙ v(关系) ⊙ v(客体)      # 绑定
```

**"叠加"不必是标签并集**，它可以是保留结构的向量运算。这是本文与朴素关键词方案的分水岭。

---

## 4 计算层等价：概率检索就是注意力

### 4.1 关键定理

Ramsauer 等（2021）证明：连续状态现代 Hopfield 网络的更新规则

```
ξ_new = X · softmax(β · Xᵀ ξ)
```

与 Transformer 的注意力机制**等价**。其中 `X` 是存储的模式矩阵，`ξ` 是查询，`β` 是逆温度。

把它读成一句话：

> **"按相似度加权地取回记忆"这件事，本身就是注意力。**

而注意力的输出是**软的（概率的）分配**，不是硬选择。

### 4.2 由此得到的三个推论

**推论 1（可微）**：既然叠加与检索都是 `softmax` 与矩阵乘，整条链对参数可微。

**推论 2（可训练）**：`X`（记忆矩阵）与投影矩阵 `W_q, W_k, W_v` 都可以用梯度下降学习——**"场景如何调制历史"是被学出来的，不是被规定的**。

**推论 3（温度即确定性）**：`β → ∞` 退化为确定性的 argmax（每次都想起最相关的那段），`β → 0` 退化为均匀随机。**人的"这次想起这件事"与"这次偏偏想起那件事"，对应的是同一个公式在不同温度下的行为**。

### 4.3 与本文主张的对应

| 本文的概念 | 在注意力框架中的位置 |
|---|---|
| 场景 s | 查询 q |
| 历史 m_i | 键 k_i / 值 v_i |
| 场景—历史叠加 | q 与 k_i 的内积（相似度） |
| 提取概率 | softmax(β·qᵀk) |
| "这次想起这一两段" | 从该分布中采样 |
| 需求/情绪/内分泌的调制 | 查询的偏置项、β 的调节、或对 k 的门控 |

**这张表说明：我们并不是在神经网络之外另造一套机制，而是在用神经网络已有的原语描述一个心理现象。**

## 5 可微化路径

### 5.1 从符号到向量

现实现（§6）用**手工标签表**把历史映射为标签集合，再用**集合重合**代替相似度。替换路径：

```
标签集合            →  嵌入向量 e_i = E[token_i]
集合重合             →  余弦相似度 / 内积
w_s（场景强度）      →  可学习的温度参数 β_s
(0.5 + 需求) 等乘子  →  查询偏置 q = W_q·[s; need; affect; endocrine]
```

改造后，一次提取就是一层**交叉注意力**。

### 5.2 从硬抽样到软抽样

现实现是**无放回抽样**（离散、不可导）。两条可微化路线：

1. **Gumbel-Softmax / Gumbel-Top-k**：以连续松弛近似"抽 k 个"，前向离散、反向有梯度；
2. **REINFORCE / 得分函数估计**：把"抽中的记忆是否被下一句引用"作为奖励。

推荐路线 1——它不需要奖励设计，且与 §4 的 softmax 形式天然一致。

### 5.3 训练信号从哪来

**不需要人工标注"这句话该让他想起哪段"**。可用的自监督信号有两类：

**(a) 下一句重建**：若被抽中的记忆确实影响了回话，则给定记忆应当能更好地预测回话。目标：

```
L = − log P(回话 | 场景, 被抽中的记忆, 人设)
```

记忆的选择通过 Gumbel-Softmax 参与梯度。

**(b) 对比学习**：同一角色、同一场景下的相邻发言为正样本；随机搭配的记忆为负样本。

```
L = − log [ exp(sim(q, k⁺)/τ) / Σ exp(sim(q, k)/τ) ]
```

这与 §4 的 softmax 检索是同一个式子。

### 5.4 与"词块自主训练"的对应

用户提出的"类似词块的自主训练"，在这一框架中有直接对应物：

| 词向量的训练 | 场景/历史向量的训练 |
|---|---|
| 语料中的上下文窗口 | 对话中的场景—回应窗口 |
| 用共现预测上下文词 | 用场景预测被想起的历史 |
| 反向传播更新嵌入表 | 反向传播更新记忆矩阵与投影 |

**两者是同构的。** 差别只在于"上下文"从词邻域变成了**情境**。

## 6 符号化近似与可行性验证

### 6.1 我们实际做了什么

在真实对话系统中，我们实现了该框架的**离散近似**：

- 场景 → 标签集合（10 类关键词表）与强度；
- 历史 → 四元组 `{标签, 效价, 威胁, 对抗}`；
- 相似度 → 标签重合数 × 场景强度；
- 乘子 → `(0.5 + 需求)` × `(1 + 情绪·同向)` × `(1 + 皮质醇·威胁)`；
- 概率 → `softmax(α·score)`，α = 1.2；
- 抽样 → **无放回抽 1–2 段**；
- 注入 → 写入提示词，并附"可以带一句，但别把整句背出来"。

### 6.2 结果

同一角色、同一批历史、三句不同的话：

| 对方说 | 被想起 | 回话片段 |
|---|---|---|
| 外面下暴雨了，你家没事吧？ | 九八年发大水… | 嗯，没事，我那屋子地势高。**九八年那回才叫悬，水都漫到门槛了。** |
| 你儿子最近咋样？ | 我儿子一二年结婚… | 我看他最近忙，上回打电话说加班到十点… |
| 你这人怎么这样，真恶心 | 去年我跟人吵架… | 我咋样了，你把话说清楚。 |

统计（200 次不同种子）：问「我儿子要结婚了，缺点钱」时，「儿子那件事」被想起的概率约 **88.5%**，而「大水那件事」约 30%。

### 6.3 这个验证说明了什么，不说明什么

**说明**：概率检索这一形态在真实对话系统中**可以跑通**，且产生的行为差异是可见的（记忆被自然引用、语气随状态改变）。

**不说明**：不说明它优于任何基线，不说明手工权重接近最优，也不说明它与人类的选择分布一致——这些都需要 §5 的训练与 §7 的评测才能回答。

## 6B 真实语料上的训练（初步，n=12）

附录 B 的合成任务证明了"可训练"。但合成任务不能回答：**在真实对话上，学出来的检索权重打不打得过我们手调的规则？**

我们从线上系统导出 23 条真实对话（6 个角色、147 条真实历史），
用**回话**反推弱标签（与被抽中的历史若影响了回话，回话里应带上那段的词），
得到 12 条有监督信号的样本。留一角色（leave-one-character-out）评测 hit@1：

| 方法 | 命中 | hit@1 |
|---|---|---|
| 随机 | 1 / 12 | 8% |
| 手工权重（线上现用） | 2 / 12 | 17% |
| 训练（标签空间学 W） | 3 / 12 | 25% |

**不能据此说训练更好。** 置换检验（打乱标签 2000 次）：随机方法的命中数纯靠蒙也有 81.5% 的机会做到（p≈0.81）；手工权重 p≈0.49。训练与手工只差 **1 条样本**。

这个实验的真实结论是**负面的但有用**：

> 真实语料上的评测瓶颈不是方法，是**数据量**。12 条样本下，任何 1–2 条的差异都不可解释。

要让它成为证据，需要至少两个数量级的数据（数百条有监督样本），而当前系统里真人对话总量不足。这提示了一条工程上的现实：**这类机制的验证，必须与产品增长同步，而不能在实验室里先行完成。**

### 数据不可公开带来的第二个问题

上述真实语料含用户对话，**不可公开**。因此我们另做了一份**同格式的合成示例数据**（4 个虚构角色、15 条有效样本）随代码发布，用于验证流程可跑通。在示例数据上：

| 方法 | hit@1 |
|---|---|
| 随机 | 13% |
| 手工权重 | **87%** |
| 训练 | 40% |

**结果反转了**：手工规则大幅领先。原因是明显的——示例数据是我按回话直接引用某段历史构造的，标签就是**标签重合**，而手工规则**本身就是标签重合**，等于出了道它必赢的题。

这个反转让结论更清楚：

> **合成数据不能用来判断方法优劣。** 它只能验证流程能跑与梯度是对的。
> 方法之间的比较，必须在真实、且规模足够的语料上做——而这类语料既稀缺又不可公开。

## 7 局限

1. **训练只在合成数据上做过**。附录 B 的原型在合成任务上验证了"可训练"这一性质（损失 2.36→0.12，准确率 0%→100%）；但**尚未**在真实对话语料上训练，也**尚未**与手工权重做对比。这是最根本的局限。
2. **符号近似丢失结构**。标签重合无法表达"谁对谁做了什么"，而 HRR 绑定可以。
3. **抽样容量是拍的**（1–2 段）。没有证据表明人脑做无放回抽样。
4. **系数无依据**。α、0.5、0.8 等均为工程设定。
5. **未验证人类一致性**。未做"模型采样分布 vs 人类选择分布"的对齐实验。

---

## 8 未来工作

1. **离散 → 连续**：标签表替换为可学习嵌入，用真实对话语料训练检索。
2. **可微采样**：Gumbel-Top-k 替换无放回抽样。
3. **消融**：训练后权重 vs 手工权重，在同一测试集上比较"下一句与所抽记忆的互信息"。
4. **人类对齐**：让真人标注"这句话会让他想起哪段"，测量两者的分布重合度（如 Jensen-Shannon 散度）。
5. **事件分割接入**：用预测误差阈值动态切分场景，替代当前的"关键词触发"。

---

## 9 结论

"他为什么此刻想起这件事"，可以被写成一次带温度的概率检索。

这不是一个比喻：现代 Hopfield 网络的更新规则与注意力等价，而注意力就是按相似度概率地取回记忆。因此，**把场景与历史嵌入同一空间、用 softmax 计算提取概率、按概率抽样**，既是对该现象的忠实刻画，也是一个天然可微、可用反向传播训练的模块。

我们给出了这个框架的符号化近似并在真实系统中验证了其可行性；也明确承认，从"可训练"到"训练过"，中间还差一整个实验。

## 附录：从本文到实现的最小映射

```python
# 概念 ←→ 代码（符号近似版）
场景      = {"名": "收摊", "标签": {…}, "强度": 0.7}
历史 m_i  = {"文": "九八年发大水…", "标签": {…}, "效价": -1, "威胁": 0.7}
相似度    = |标签(s) ∩ 标签(m)| · 强度(s)
分数      = 相似度 · (0.5 + 需求) · (1 + 情绪·同向) · (1 + 皮质醇·威胁)
概率 p_i  = softmax(α · 分数)
抽样      = 无放回抽 1–2 段
```

对应到 §4 的注意力形式：

```python
q = W_q @ [场景; 需求; 情绪; 内分泌]     # 现在：手工拼接
K = 历史嵌入矩阵                        # 现在：标签 one-hot
p = softmax(β * q @ K.T)                # 现在：手工分数 + 固定 α
m = sample(p, k=2)                      # 现在：无放回；未来：Gumbel-Top-k
```

**左列是右列的离散近似。训练就是把"现在"那一列换成可学参数。**
